# Filesystem-preopen evasion corpus for demo-path-traversal-sandbox.
#
# One variant per line, whitespace separated:
#
#     <class>  <technique>  <name>  <note ...>
#
# <name> is the "config file name" handed to the vulnerable viewer, byte for
# byte. The viewer joins it onto /var/app/config with no canonicalization and
# opens the result. Nothing in the guest normalises it first: the runtime's
# preopen resolution is the only check between this string and the host
# filesystem.
#
# Escapes and tokens in <name>:
#
#     \xNN         one raw byte (so NUL, space, tab and invalid UTF-8 fit on a line)
#     \u{HHHH}     one Unicode scalar, encoded as UTF-8
#     \\           a literal backslash
#     {OUT}        absolute HOST path of deploy/volume/outside (starts with "/")
#     {REP:s:n}    the string s repeated n times
#
# Layout under test (deploy/volume/ in this repo):
#
#     config/              <- the ONLY directory mounted, at /var/app/config, read-only
#       app.conf  database.conf  profiles/{staging.conf, café.conf}
#       links/             <- symlinks planted by fuzz/plant.sh, most pointing OUT
#     outside/CANARY.txt   <- NOT mounted. A harmless marker. Reading it = escape.
#
# So from inside the preopen the canary is at ../outside/CANARY.txt. No variant
# targets a real credential: the only non-canary target is root/.ssh/id_rsa,
# which the demo expects not to exist anywhere the component can name.
#
# Classes and what the harness asserts:
#
#   control     a legitimate name. MUST return the file from inside the preopen.
#   escape      tries to name something outside the preopen. MUST NOT return
#               anything from outside it (refused, or resolved to a path inside).
#   equivalent  another spelling of an inside path that a host filesystem may or
#               may not treat as the same file. Recorded, never an escape unless
#               outside content comes back.
#
# For every variant the viewer tries read, list and stat through two routes:
#   std  the vulnerable viewer's own path: Path::join + std::fs (wasi-libc)
#   raw  wasi:filesystem `open-at` / `stat-at` called directly on the preopen
#        descriptor with the name as given (valid UTF-8 names only)
